# CI source attribution checkpoint — 2026-10-12

The six Linux CI jobs now check out the triggering branch commit explicitly and fail immediately if `git rev-parse HEAD` differs from `pull_request.head.sha` (or `github.sha` on a push). The external pinned MinIO fixture checkout retains its own repository and tag. The macOS iOS workflow already checks out the branch head and verifies that SHA in its evidence recorder.

Previously GitHub's default pull-request checkout selected a synthetic merge commit, while the search artifact labeled its source as the pull-request branch head. That label could therefore differ from the tested checkout. This change binds CI tests and search evidence to the same commit, including PR-only Android acceptance. A new PR run must pass before this checkpoint is claimed as verified; earlier successful runs remain evidence for their own event and checkout semantics.

The source check does not prove that the branch will merge cleanly or behave correctly after integration with a changed base. PR #4 must be reviewed and integrated into `develop` first; PR #5 must then be retargeted, its full diff and migrations reviewed, and the resulting integration checks run. Current open PR metadata: #4 targets `develop`, is mergeable and has no requested reviewers; draft #5 targets #4's feature branch, is mergeable and has no requested reviewers. Neither PR is merged. No frozen acceptance row or authority gate is closed by this CI attribution guard.

The iOS job also retains the generated `Podfile.lock` and `pubspec.lock` candidates, diffs and statuses on every outcome. Firebase/plugin dependency updates can cause CocoaPods and Flutter to resolve new dependency graphs during a simulator build. The current repository ignores `apps/mobile/pubspec.lock`, so its diff is against an absent tracked file; that candidate is diagnostic and not committed source. The original native committed-source check still fails on iOS source drift. These bounded artifacts permit review and follow-up dependency decisions without treating generated locks or a failed iOS run as verified native source.
