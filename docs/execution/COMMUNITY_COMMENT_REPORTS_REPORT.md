# Community comment reports and independent review

Migration 037 retains categorized comment reports with exact bigint sequence cursors, original explanatory reason, status, review notes and timestamps. One open case per comment/reporter prevents duplicate submissions; retries retain the first report. ABUSE, PRIVACY, SPAM and OTHER are validated categories. This bounded catalog is not a configurable approved moderation policy. Reporting requires a current visible published conversation and live same-post comment; it does not hide the comment or change publication state automatically.

Independent current scoped moderators browse at most 50 newest cases per post with older/latest navigation. Post authors cannot access the case console; a comment author or reporter cannot see/review their own case there. No reporter/author/reviewer IDs are returned. Free text may self-identify and is not promised anonymous. Retained removed comment text is available only in the authorized case console. Hidden/deleted conversations retain evidence but ordinary access remains refused; deletion or removal outside case review withdraws open reports.

KEEP closes the selected case with notes. REMOVE logically removes the comment and closes all open cases for it, requiring independence from every open reporter. Current post/case/comment locks serialize review/removal; stale, resolved or removed cases return conflict. Audit intent and decisions/removal commit together; audit failure rolls them back. Source records and children remain. Report reasons are not copied into audit notifications; this checkpoint emits no external notices. Rollback refuses existing case evidence.

Web and Flutter provide report category/reason entry, private case browsing and reason-bound keep/remove review. Server authority is enforced independently of UI controls. Browser coverage reports a retained comment and independently keeps it; mocked native coverage checks exact sequence above JavaScript safe integer range, required notes and refreshed decision. Two real PostgreSQL cases cover duplicate reports, privacy, self/reporter review refusal, keep/stale/remove, concurrency, audit rollback, withdrawal, 53-case pagination, invalid cursors and retained deletion evidence.

Exact-head CI is recorded in PR #5. User reporting, configurable reason catalogs/policy, restoration/restriction/escalation, author outcome/appeal paths, deleted-post case management and full bilingual/device/load/security/accessibility/retention/provider/authority acceptance remain mandatory. All 260 original acceptance records and 31 exact frozen NFR targets remain unchanged/open. No merge, deployment or real-user migration.
