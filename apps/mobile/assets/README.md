# Heritage UI assets

The tree illustration is from the owner's supplied Stitch design ZIP (golden family-tree illustration screen). The temple image uses the image URL embedded in that ZIP's `premium_home_dashboard/code.html`.

Inter, Playfair Display and Noto Sans Devanagari are bundled from the corresponding `ofl` families in the official google/fonts repository. Their SIL Open Font License texts are included beside the font files. Bundled fonts avoid runtime font downloads and provide Nepali glyphs offline.

Member portraits are loaded only through authorized application services; reference portraits and fictional member records are not bundled.
